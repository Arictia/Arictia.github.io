salvia_brief

Salvia 意为鼠尾草，一种可药用的草本植物，拉丁语义为“净化”。而在这里，它指代的是一个女人。

Salvia.是作者以架空上世纪美国为背景创作的原创小说，主要讲述了一对没有血缘的兄弟在沉重过去驱赶下如何走向他们的结局，所有的故事都已经尘埃落定（指大家都已经死了），阅读前请注意首页的警告信息。

本作品已经进入出版流程，博客内不再提供正文部分的完整内容，欢迎感兴趣的朋友线下购买阅读 ^ ^

以下内容可能包含剧透。

// BASIC PROFILE

01 / 家庭背景

  • 作为埃斯波西托家族的次子、西莱斯特·博纳罗蒂与薇薇安·华特的孩子出生，其本质上是由于西莱斯特对长子失望而诞生的新的继承人
  • 被萨尔维娅带走后，几乎失去了对家人的所有印象。
  • 重新回到埃斯波西托家后，虽然受到安东的关注和西莱斯特的漠视，但本人并无特别的情绪

02 / 现状

  • 因病情加重主动寻找了医生，并协助对方修建了疗养院，将自己困居其中
  • 被萨麦尔找到后，被迫同对方开始公路旅行，最后在海边被萨麦尔杀死
// PERSONALITY

01 / 性格

  • 是一个冷漠又伪善的人。冷漠遗传自西莱斯特人格上的本质，对于不侵害到他利益的人全然不在乎；伪善则来自对萨尔维娅的反抗，他不愿意成为她希望他成为的样子。
  • 无法真正的行善，没有同理心和同情心
  • 因为受到萨尔维娅扭曲的教育，无法自控地将杀戮视作释放情绪的方式，同时也无法再将人命视作有价值的东西

02 / 外表

  • 黑发灰眼，后发稍长，长相有八分和西莱斯特相似，行为举止上则更类似萨尔维娅
  • 从手腕到上臂都有注射针孔和因注射导致的乌青，体态消瘦，骨瘦嶙峋，一眼就能看出是个病人

03 / 爱好

  • 杀人
// MEDICAL HISTORY

01 / 病情

  • 严重的CPTSD，经常出现幻觉，无法分清现实和幻想，行为不受控制
  • 严重的失眠导致过度药物依赖
  • 解离频率高、时间长，经常处于木僵状态

02 / 病史

  • 自从14岁杀死萨尔维娅、逃离她的掌控后，精神并未从压抑和扭曲中离开，反而长期受困，并在后来的寄宿学校生活中病情进一步发展
  • 直到24岁才开始接受精神治疗，但在当时条件下，所有医疗手段对他的病情都没什么帮助
// IF RECORD

01 /CROSSOVER

  • 和无影灯下系列的crossover，在这一if中，艾利克斯于大学时期被肯尼斯找到并带走了。
  • 其后同肯尼斯一起生活，对方去世后，作为养子继承了他的财产，后独居于家族名下的房屋中
  • 干扰了萨麦尔与娜塔莉娅的婚姻，令两人都陷入了不幸中

02 / 蜘蛛艾利IF

  • 没有杀死萨尔维娅而是杀死了萨麦尔的情况，屈从于妈妈的影响，真正地成为了她的儿子
  • 即使如此，也在若干年后，将西莱斯特和萨尔维娅一并杀死
  • 这个IF里，艾利克斯的精神要健康得多；同时，这个IF也是最像西莱斯特与萨尔维娅结合生下来的孩子的一个

03 / 现代PARO

  • 故事发生的时代来到了现代，在这里，萨尔维娅得到了她的心上人，杀死了西莱斯特
  • 在萨尔维娅若即若离的看顾下上完了大学，就读药学系，毕业后在制药公司工作
  • 同萨麦尔、娜塔莉娅这对情侣都保持着肉体关系，但不喜欢他们中的任何一人

01 / 家庭背景

  • 出生于东欧的孤儿，三岁左右的时候在街上被萨尔维娅捡走，作为被她用于练习如何做一个母亲的道具存在
  • 尽管憎恶、嫉妒着妈妈后来带回来的艾利克斯，也还是承认对方是自己的兄弟，是这个家庭的一员，在乎着艾利克斯
  • 深爱着萨尔维娅，几乎将之扭曲为了一种信仰，在萨尔维娅死后妄想对方活在自己身上

02 / 现状

  • 十四岁伙同艾利克斯杀死妈妈后，依靠萨尔维娅传授的知识靠杀人为生
  • 在杀死艾利克斯、使一家人团聚后，精神逐渐失控，四十一岁时死于任务途中
// PERSONALITY

01 / 性格

  • 原本的个性已然不复存在，构筑其本色的是对母亲的爱和对兄弟的嫉妒，可以说萨麦尔一直是个心智不健全的孩子，而他这样也是因为，这是在萨尔维娅手下讨生活所必须的模样
  • 行为和思考逻辑都以直觉为主，尤其是在面对艾利克斯的时候
  • 很多地方都在模仿萨尔维娅，接受了她“杀死即是爱”的理念，虽然会通过杀人取乐，但和艾利克斯不一样，并不真正享受杀戮
  • 急性子，不喜欢绕弯子，讨厌装模做样

02 / 外表

  • 黑发蓝眼，都是染的。脸上因为整容手术整体看起来不太协调，给人轻微恐怖谷的感觉，五官看起来介于男女之间
  • 四肢修长匀称，没有很多肌肉，身上有去除刺青后的痕迹，为了遮掩骨架一般穿领口和胸脯有大量装饰的裙子，戴长手套
  • 小时候发色接近金棕，眼睛是褐色，五官秀气讨喜

03 / 爱好

  • 没有属于自己的爱好
// MEDICAL HISTORY

01 / 病情

  • 严重的妄想症，无法分清现实和幻想，长期幻听幻视，现实感知力差
  • 疑似躁狂倾向

02 / 病史

  • 未接受过治疗
// IF RECORD

01 /CROSSOVER

  • 在这里萨麦尔也找到了艾利克斯，在和对方斗法的同时认识了娜塔莉娅，两人最开始是炮友，后来因为有了孩子，萨麦尔最终同意了结婚
  • 但因为艾利克斯的插手，二人的感情留下了不可弥合的裂痕，同时萨麦尔的精神也向着无法挽回的方向坠落
  • 最终，他和娜塔莉娅一同葬身火海

03 / 现代PARO

  • 依旧是被萨尔维娅收养的孤儿，同样在萨尔维娅若即若离的看顾下长大，没有上大学，选择成为了一名特效化妆师
  • 同时也在做油管主，分享化妆教程
  • 和娜塔莉娅是情侣，但也同时与艾利克斯保持着肉体关系，尽管如此，并非将对方作为恋爱的对象而是家人

// BASIC PROFILE

01 / 家庭背景

  • 博纳罗蒂家族的长女，因为其天生的反社会人格被作为大家长的祖父看重，亲自抚养
  • 和西莱斯特有非常远的血缘关系，实际上称呼西莱斯特为表兄只是在恶心人
  • 并不认为祖父之外的亲人是自己的亲人，对他们没有感情，同样的，她的父母和兄弟姐妹也畏惧与排斥着和他们似乎有本质区别的她

02 /观念

  • 某种意义上只认可和她一样是反社会的人才是人，教育孩子们、把他们变成自己的家人也不过是心血来潮
  • 在祖父死后，只认为西莱斯特是和自己一样的存在
// PERSONALITY

01 / 性格

  • 杀戮（即，终止生命）对她来说是空气和饮水一般的必需品，也对此没有任何心理负担
  • 没有道德观、善恶观和伦理观，做事全凭自己的心意
  • 教养和教育塑造了她的行为表现，但那只是因为“需要这么做”而不是其他
  • 在旁人看来她喜怒无常，实际上并没有多少感知负面情绪的能力

02 / 外表

  • 黑发蓝眼，拥有完全符合男性对女性之美的想象的美貌，整体气质表现得有些柔弱，给人蛋彩画上的精怪般的印象
  • 偏好古典繁复的服饰，其实来自祖父的审美习惯，她本人虽然在乎美，但并不认为这样是美的。

03 / 爱好

  • 杀戮，欣赏受害者的痛苦与不幸
  • 制作标本
// MEDICAL HISTORY

01 / 病情

  • 天生的虐待狂和反社会，尽管在祖父的教育下披上了人皮，但精神上的异质全无改变
  • 在精神病院的十年让她更加只沉浸在自己的世界里，存在精神分裂的可能
// IF RECORD

01 / 性转IF

  • 在这样的故事里，他们追寻的也还是西莱斯特
