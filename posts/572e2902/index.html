 2026.3.13  心因症  4011  9 分钟

心因症 所指的并非现实存在的疾病，而是一种非器质性的病变导致的情绪波动、行为紊乱及躯体化症状。也许，在这个故事里，它可以指代“爱”。

心因症是作者以架空现代日本为背景创作的原创小说，主要讲述了两个彼此爱着的人，如何摆脱那些缠绕在他们身上的痛苦，拥抱彼此的故事。爱是一种诅咒，但他们还是在这样的力量的指引下，选择继续活下去。

  • 可供代餐的主题曲：《鬼ごっこ》春野 self cover

存在和现实不符的设定表现，以及对医学的误用和伤痛的轻量化描写

以下内容可能包含剧透。

// BASIC PROFILE

01 / 家庭背景

  • 出生于东京的精密机械制造企业家庭，自幼丧母，有一个相差十岁的哥哥（雾人）一个相差六岁的妹妹（美奈子）。
  • 与父亲感情淡薄，对妹妹和继母心存愧疚，目前只与哥哥还保持着联系。从高中开始离家求学，法律意义上的监护人是哥哥。

02 / 现状

  • 因防卫过当杀人，缓刑中，每个季度必须与指定的医生会谈，并接受社工上门回访。
// PERSONALITY

01 / 性格

  • 性格很差，被害妄想症严重，对接近自己的人充满攻击性
  • 厌恶和人打交道，社交恐惧已经发展到会为此暴起攻击他人的地步
  • 对教师等职业没有好感，厌恶权威，喜欢没有攻击性、温和、情绪稳定的人
  • 对使用暴力没有自省（神原除外）

02 / 外表

  • 脸非常精致，五官优越到给人中性感的印象。似乎总能吸引一些奇怪的人的注意，从小被这个问题困扰，几乎没有过正常的社交，也曾因此遭受过严重的霸凌。
  • 大学被星探搭讪过几次后把头发染成了白色，并为了避免他人的靠近服装逐渐换成了涩谷风
  • 外出时会佩戴左金右红的美瞳和夸张的饰品

03 / 爱好

  • 喜欢电子游戏、文艺书籍和垃圾食品，不了解也不关心当下的流行
  • 对需要投入大量时间精力的游戏类型情有独钟
  • 喜欢的音乐风格是地牢合成器和比较重的摇滚
  • 酒量不佳，喜欢吃重口味的食物，不会做饭
  • 喜欢文艺类的电影，不喜欢血浆片
// MEDICAL HISTORY

01 / 病情

  • 罹患C-PTSD和双相情感障碍，服药中
  • 语言功能受损， 本人几乎不使用敬语，因为精神状态的缘故，无法在非情绪激动状态下正常说话，表现为停顿不恰当和语序混乱
  • 情绪管理功能受损，容易陷入歇斯底里和解离状态
  • 严重的被害妄想，惶恐发作时出现幻觉，现实感丧失，无发作时的记忆
  • 躯体化通常表现为木僵、颤抖、头痛，经常食管反流和呕吐

02 / 病史

  • 小学时被校医猥亵，并因此受到他人排挤，出现若干情绪管理和社交问题，开始接受心理治疗，但直到高中才获得诊断
  • 初中时因被绑架的后遗症开始接受精神医生的治疗
  • 高三时的车祸后，住院疗养一年，并接受MECT治疗
  • 大学时自杀未遂，后退学，中途断药一段时间
  • 防卫过当杀人后，持续接受治疗
// IF RECORD

01 / 恐怖片IF

  • 若初中时并未就读于寄宿学校，而是转入介护机构下的学校进行家庭教育，精神状态和人格发育比本篇完善许多
  • 高中时并未转学到京都，而是普通地在东京上学，也没有遭遇车祸，最终考上了东京大学
  • 与神原在大学时的一次学术交流活动中于京都相识，大学毕业时开始同居
  • 就职于自家公司，作为技术统括驻场于某国家物理研究所，也负责一部分课题评审工作

02 / MOB IF

  • 没有发生车祸的世界线，和神原读了不同的大学，但在大学时被奇怪的人绑架并MOB了！
  • 因为被注射毒品身体发生了奇怪的改变

KANBARA SEIJI
神原　静司（かんばら　せいじ）
AGE 28
STATS 170CM/58KG
SEX MALE
BIRTH 1981.3
ORIGIN KYOTO
OCCUPATION TRANSLATOR
// BASIC PROFILE

01 / 家庭背景

  • 出生于京都寺院家庭，父母各自有自己的生活，4岁起由大伯一家抚养
  • 只将大伯一家视作自己的亲人，对母亲心态复杂，对父亲毫无关心

02 / 现状

  • 故事开始时保留了双腿和部分行走能力，结局后双腿自小腿中段截肢
  • 结束了在美国的学业后回国，就职于某跨国企业的市场部，五年后和秋山一起移居美国
// PERSONALITY

01 / 性格

  • 对外温和有礼，没有攻击性，擅长处理人际关系和解读他人意图，待人接物十分有分寸，经常做团体里的润滑剂
  • 实际非常有自己的主意，个性凉薄，以自己的感受来认知世界
  • 有不自觉操纵他人的倾向，也可以说把这样的行为作为解压方式来做
  • 对待爱情有极端和扭曲的部分，belike“全人类的幸福那种东西抵得上我爱情的十分之一就不错了”

02 / 外表

  • 去美国后留了长到腰际的头发，每天都要把它们梳成麻花辫
  • 非常日本人的长相，五官柔和，眼尾上翘，单眼皮，不笑的时候有距离感
  • 在乎自己的外表，每天都化妆，会用香膏

03 / 爱好

  • 偏好清淡的饮食习惯和柔软舒适的衣服，注重生活质量
  • 似乎喜欢和擅长的东西不少，但只是为了合群而已
  • 会做饭，酒量不错，很会照顾人；会开车，有驾照
  • 最喜欢的作家是泉镜花
// MEDICAL HISTORY

01 / 病情

  • 双腿因车祸复杂性骨折，经过再生手术和长期复健后能够短时间行走（不超过 10 分钟）和站立（不超过 30 分钟），无法跑跳、下蹲、跪坐，阴雨天双腿骨头会痛，出行基本靠轮椅
  • 双腿胫骨侧有排列的 Llizarov支架留下的圆形针道眼疤痕，皮肤多处植皮，肤色有黄色断层，呈蜡质感
  • 腿部线条僵硬、锐利，小腿皮肉紧贴骨头，看得到血管纹路；大腿骨结合处有细微折角；腿部皮肤有十几道纵横交错的长疤痕，有的增生有的下陷
  • 因多次唤醒麻醉手术经历身体经常幻痛，时常因天气变化骨骼内部酸痛，需要服药
  • 因保肢手术和康复期的经历，罹患双相情感障碍，经常陷入伤害自己身体的过激幻想中，偶发幻觉
  • 躯体化表现为因情绪起伏导致的神经性疼痛、呼吸困难、哭泣、心跳过速

02 / 病史

  • 直到故事开始时都仅接受双腿的复健和定期检查，在美国接受过固定的心理治疗
  • 故事结束移居美国后开始接受精神类药物治疗
// IF RECORD

01 / 恐怖片IF

  • 普通地在高中毕业后考上了京都大学文学部，大二时的学术交流活动中和秋山相识相恋，毕业后为了和对方同居在东京读硕士。
  • 博士毕业后在某社科研究所工作，主攻宗教学方向
  • 因为对目前两人的感情生活有些不满，利用主持的项目实施了献祭仪式，导致近十人死亡，且受害群体扩大中，自己也因为仪式的代价而心衰而死
  • 死后盘桓在家中，想要将秋山也带走

02 / MOB IF

  • 没有发生车祸的世界线，在得知秋山遭到了这样的对待后主动接手了照顾对方的工作
  • 对于恋人变成这种样子，既感到痛心，又有相当的不满，可即使如此……

03 / 邪教IF

  • 同样没有发生车祸的世界，和秋山在大学时期在一起了，读的是心理学
  • 然而好景不长，某天秋山自杀了，为了复活所爱之人，开始求助于超自然力量
  • 利用心理咨询师的身份发展了一些信徒，目的是获取祭品，用这些人的头来换取恋人的复活
  • 同样梳着长麻花辫，但每天穿着丧服
